APK বানানোর ধাপ:
1. github.com এ বিনামূল্যে অ্যাকাউন্ট খুলুন, নতুন repository বানান।
2. এই ফোল্ডারের সব ফাইল (লুকানো .github ফোল্ডারসহ) upload করুন।
3. Actions ট্যাবে যান -> "Build APK" শেষ হলে (প্রায় ৫ মিনিট) -> নিচে "salah-apk" ডাউনলোড করুন।
4. zip খুলে app-release.apk ফোনে পাঠান ও install করুন।
